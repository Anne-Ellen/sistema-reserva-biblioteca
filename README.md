# Sistema de Reserva de Biblioteca

Projeto acadêmico desenvolvido durante a graduação em Engenharia de Software.

## Sobre o projeto

Sistema desenvolvido para representar e organizar as operações de uma biblioteca, utilizando um banco de dados para armazenar e gerenciar informações relacionadas a livros, usuários e empréstimos.

## Tecnologias utilizadas

- SQL
- MySQL

## Conceitos de banco de dados aplicados

- Modelagem de banco de dados
- Criação de tabelas
- Definição de chaves primárias e estrangeiras
- Relacionamentos entre tabelas
- Comandos SQL (DDL e DML)

## Arquivos do projeto

- Arquivos `.sql` contendo a estrutura e os comandos do banco de dados.
- Documento PDF com a descrição do trabalho.

## Objetivo

Aplicar conhecimentos de banco de dados, desenvolver habilidades com SQL e compreender a estruturação e organização de informações em um sistema.
